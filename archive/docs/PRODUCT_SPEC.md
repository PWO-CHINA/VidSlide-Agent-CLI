# 产品说明

## 产品目标

构建一个 AI Agent 可直接调用的 VidSlide CLI。

主要能力：

-   视频输入检查
-   PPT 提取
-   提取结果质量检查
-   异常定位
-   基于证据恢复
-   最终导出

## 产品不是

本项目不是：

-   新的视频理解算法研究
-   人类 GUI 工具
-   通用视频处理平台
-   自动生成课程内容系统

## 设计思想

程序负责：

-   搜索异常
-   保存证据
-   管理状态

AI Agent 负责：

-   少量视觉语义判断
-   根据证据做决策

不要让 AI 替代程序可以稳定完成的工作。
